# Add PDF Download Button Prompt for Antigravity

You are modifying an existing SpendWise project.

## Objective

Implement a PDF download button in the advisor chat interface.

### Expected Behavior

#### Conversational Flow

When the Intent Router classifies a query as `conversational`:

- Show the generated LLM response exactly as today.
- Do NOT show any PDF download button.
- Do NOT generate any PDF.
- Do NOT change the conversational pipeline behavior.

Example:

User: "Hi"

Output:
- Greeting message displayed.
- No PDF button.

---

#### Financial Analysis Flow

When the Intent Router classifies a query as `financial_analysis`:

- Continue displaying the generated response text in chat.
- Generate a PDF report.
- Show a download button directly below the corresponding assistant response.
- Allow users to download the generated PDF.
- Preserve all current functionality.
- Do not remove or change the displayed response text.

Example:

User: "Analyze my budget"

Output:
- AI financial summary displayed.
- Recommendations displayed.
- Download Report button displayed.

---

## Implementation & Summary of Changes Made

### 1. `agents/tools.py` Modifications
- **Enhanced `pdf_report_tool`**:
  - Implemented dynamic chart generation functions `_generate_pie_chart` and `_generate_bar_chart` using Matplotlib with headless `'Agg'` backend.
  - **Pie Chart**: Visualizes Income & Budget Allocation (Expenses, EMI/Debt, Surplus/Savings).
  - **Bar Chart**: Visualizes key financial comparison metrics (Monthly Income, Expenses, EMI, Savings, Emergency Target).
  - Both charts are automatically rendered and embedded side-by-side inside the ReportLab PDF layout.
  - Formatted all 9 required PDF content sections:
    1. **Cover Section Banner**: Brand header, client name, persona, generation timestamp.
    2. **Executive Summary**: Displays `report_agent` summary.
    3. **Financial Metrics Table**: Displays actual values calculated by `calculator_agent` (Monthly Income, Monthly Surplus, Savings Rate %, DTI Ratio %, Recommended SIP, Emergency Fund Target).
    4. **Recommendations Section**: Displays `recommendation_agent` recommendations.
    5. **Trade-Off Analysis Section**: Displays strategy, benefits, and drawbacks/trade-offs from `trade_off_agent`.
    6. **Market Insights Section**: Displays `market_context` observations from `market_react_agent`.
    7. **Portfolio Visualization Section**: Contains embedded Pie Chart and Bar Chart.
    8. **Closing Summary**: Summarizes overall financial health & key next steps.
    9. **Disclaimer Section**: Footer disclaimer.

### 2. `frontend_app.py` Modifications
- **Chat History & PDF Button Integration**:
  - Updated `advisor_response` function to extract `pdf_path` returned from the `/chat` endpoint.
  - Updated `submit_advisor_question` to store `pdf_path` alongside assistant messages in `st.session_state.advisor_messages`.
  - Updated `advisor_chat` rendering loop to check each assistant message for `pdf_path`. If non-empty and valid on disk, renders a `st.download_button` (`📥 Download Financial Report (PDF)`) directly below the assistant message.
  - Rendered nothing if `pdf_path` is empty (for `conversational` queries such as "Hi").
  - Ensured unique Streamlit button keys using message index and filename (`key=f"download_pdf_{i}_{filename}"`).
  - Preserved full chat history, onboarding flow, and existing UI aesthetics.

### 3. `backend_app.py`
- Confirmed `/chat` endpoint returns `pdf_path` (empty string for `conversational` queries and PDF path string for `financial_analysis` queries) without requiring breaking schema changes.

### 4. Verification & Testing
- Executed full end-to-end pipeline tests:
  - `conversational` query ("Hi"): Correctly yields `pdf_path: ""` and no PDF download button.
  - `financial_analysis` query ("Analyze my budget"): Correctly generates PDF report with all required sections and charts, returning the PDF path to display the download button.
